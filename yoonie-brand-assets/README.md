# Yoonie Brand Assets — concept pack

Palette:
- Warm Linen `#F5EBDD`
- Soft Sage `#D8E6DA`
- Forest Green `#28594E`
- Honey Amber `#E8A45B`
- Charcoal `#303A36`

## Folders
- `mascot/`: six individual transparent PNG crops from the generated mascot concept sheet.
- `logos/`: editable SVG concept lockups: horizontal, wordmark, stacked, and app icon.
- `palette/`: palette reference sheet.
- `reference/`: original generated source sheets for reference.

## Notes
These are concept assets, not final production artwork. Mascot PNGs are raster images and may include soft rendered shadows. SVG logos are editable and use a system sans-serif fallback; convert typography to outlines and refine spacing before production. The logo concepts are clean vector interpretations of the moodboard, not exact extractions from the composite board.
